# Running-app pixels — PR #218 (`feat/general-landing-memories-v2`)

Captured from the running app at head `9b82bc5` (cache-bust v342), every state
the General Landing + Memories v2 spec asks for, at 393 and 320 CSS px, plus
light / dark, reduced motion and 200% text (the 200% pass also runs at 280px,
because CI's fonts lay the same string wider than a Mac's).

This branch exists only to host these images so they render inline in the PR.
It is an orphan branch — it shares no history with `main` and is never merged.

**The media is synthetic.** The design pass itself was graded against real
photos, per the project's "real photos first" rule, but those are the owner's
personal library and this repository is public, so publishing them here was not
mine to do. The stand-ins are generated stage-light gradients at the same
aspect ratios, so layout, cropping, cover selection and contrast are still
graded on real pixels — only the subject is invented. The real-photo bundle
stays private.

`pixels/report.json` carries the automated layout/a11y measurements taken
alongside each shot.
